## Blueprint summary

| Partner type | Primary solution | Key modules |
| --- | --- | --- |
| CPMS | Home charging reimbursement | Session Ingestion, Tariff Engine, Reimbursement |
| Fleet Platform | Home charging reimbursement + Fleet reporting | Driver Onboarding, Session Ingestion, Tariff Engine, Reimbursement |
| Charger Manufacturer | Home charging reimbursement | Charger Integration, Session Ingestion, Tariff Engine, Reimbursement |
| Leasing Company | Home charging reimbursement | Driver Onboarding, Session Ingestion, Tariff Engine, Reimbursement |
| Energy Supplier | Tariff-based costing + Energy payments | Tariff Engine, Reimbursement, Energy Payments |
| Vehicle OEM | Session attribution + Reimbursement | Vehicle Integration, Session Ingestion, Tariff Engine |
| Mobility Service Provider | Home charging reimbursement | Driver Onboarding, Session Ingestion, Tariff Engine, Reimbursement |
| White-Label Platform | Complete branded product | All modules |

Each blueprint contains the target outcome, what you own versus what Rightcharge provides, required and optional modules, an architecture diagram, the user journey, API and webhook requirements, failure paths, sandbox acceptance criteria, and a go-live checklist.
