Rightcharge modules are the building blocks of the platform. Pick the ones you need and combine them to create the solutions your business requires, whether that is home charging reimbursement, tariff-based costing, energy payments or fleet reporting.

  </Card>

  </Card>

  <Card title="Vehicle Integration" href="/modules/vehicle-integration">

## Module dependencies

Some modules depend on others. Use the table below to understand which modules you need to enable for your chosen solution.

| Module | Depends on | Required for |
| --- | --- | --- |
| Driver Onboarding | None | All solutions |
| Charger Integration | None | Home charging reimbursement, fleet reporting |
| Vehicle Integration | None | Improved accuracy (optional) |
| Session Ingestion | Charger Integration (or direct submission) | Tariff-based costing, reimbursement, fleet reporting |
| Tariff Engine | Session Ingestion | Tariff-based costing, reimbursement |
| Eligibility & Policy | Session Ingestion, Driver Onboarding | Reimbursement |
| Reimbursement | Tariff Engine, Eligibility & Policy | Home charging reimbursement, energy payments |
| Webhooks | None | All solutions (recommended) |

<Note>
  Not all modules are required for every solution. See [solutions/overview](/solutions/overview) for a full mapping of modules to solutions.
</Note>
