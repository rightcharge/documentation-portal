Rightcharge emits webhooks for all significant lifecycle events. Subscribe to relevant events to drive automation in your platform, such as updating a driver record, triggering a payment or notifying a fleet manager.

## Event categories

Rightcharge webhooks cover the following lifecycle areas:

- **Driver lifecycle**: invitation sent, onboarding started, onboarding completed, onboarding failed.
- **Session lifecycle**: session ingested, session validated, session costed, session rejected.
- **Reimbursement lifecycle**: reimbursement created, reimbursement approved, reimbursement rejected.
- **Policy events**: session failed eligibility or fraud check.

## Delivery

Rightcharge delivers webhooks as HTTPS POST requests to a partner-registered endpoint. Each payload includes the event type, a timestamp and the relevant resource data.

If a delivery fails, Rightcharge retries automatically.

[PLACEHOLDER: retry schedule — see api-reference/webhooks/retries]

## Verification

Every webhook includes an HMAC-SHA256 signature in the header. Verify the signature in your endpoint to confirm the payload came from Rightcharge. See [guides/webhook-verification](/guides/webhook-verification) for implementation steps.
