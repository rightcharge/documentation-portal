## Response structure

List endpoints return an envelope containing the data array and pagination metadata:

```json
{
  "data": [
    { "id": "drv_123", "first_name": "Alice", ... },
    { "id": "drv_456", "first_name": "Bob", ... }
  ],
  "meta": {
    "next_cursor": "abc123",
    "total": 142
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `data` | array | The resource objects for this page |
| `meta.next_cursor` | string | Cursor for the next page (null if last page) |
| `meta.total` | integer | Total number of results across all pages |

## Iterating through pages

Fetch the first page without a cursor, then use `meta.next_cursor` from each response to request the next page until it is null.

```bash
curl -X GET "https://[PLACEHOLDER: base URL]/v1/drivers?limit=25" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Use the returned cursor for the next request:

```bash
curl -X GET "https://[PLACEHOLDER: base URL]/v1/drivers?limit=25&cursor=abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Stop when `meta.next_cursor` is null or `data` is empty.
