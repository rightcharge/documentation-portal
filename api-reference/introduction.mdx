The Rightcharge API is a RESTful HTTP API. All requests use JSON. Authentication is via API key in the `Authorization` header. This page explains how requests and responses are structured, how to choose the right environment, and how the rest of this reference is organised.

## Request format

All requests must include:

- `Content-Type: application/json` for requests with a body
- `Authorization: Bearer YOUR_API_KEY`
- A valid JSON body for `POST` and `PATCH` requests

## Response format

All responses return JSON. Success responses include the resource object. Error responses include a standard error envelope.

### Error response structure

```json
{
  "error": {
    "code": "invalid_request",
    "message": "The request body contains invalid fields.",
    "details": [
      {
        "field": "email",
        "issue": "must be a valid email address"
      }
    ]
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `code` | string | A machine-readable error code |
| `message` | string | A human-readable description of the error |
| `details` | array | Optional field-level validation errors |
