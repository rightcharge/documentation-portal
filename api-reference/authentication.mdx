All Rightcharge API requests must include a valid API key in the `Authorization` header. This page describes the header format, key types, how to obtain keys, and what happens when authentication fails.

## Header format

Pass your API key as a Bearer token:

```text
Authorization: Bearer YOUR_API_KEY
```

## Error responses

### 401 Unauthorized

Returned when the request is missing an API key, or the key is invalid or revoked.

```json
{
  "error": {
    "code": "unauthorized",
    "message": "The API key provided is invalid or has been revoked."
  }
}
```

### 403 Forbidden

Returned when the API key is valid but does not have sufficient scope for the requested operation.

```json
{
  "error": {
    "code": "forbidden",
    "message": "The API key does not have permission to perform this action."
  }
}
```
