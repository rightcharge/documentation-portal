## Acknowledging events

Return any `2xx` HTTP response as quickly as possible to acknowledge receipt. Process the event asynchronously in your own queue or worker to avoid timeouts.

<Tip>
  Acknowledge immediately and enqueue for async processing to avoid timeouts. Heavy processing inside the webhook handler increases the risk of retries.
</Tip>

## Best practices

- Respond with `2xx` before doing any heavy work.
- Store the event ID and check for duplicates if your handler is not idempotent.
- Monitor your endpoint response times and error rates in the partner dashboard.
