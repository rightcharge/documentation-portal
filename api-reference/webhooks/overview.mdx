Rightcharge sends webhook events to your registered HTTPS endpoints when resources change state. Use webhooks to keep your platform in sync without polling, for example updating a driver record when onboarding completes or triggering a payment when a reimbursement is approved.

Your endpoint must be an HTTPS URL that can accept `POST` requests.

## Payload structure

All webhook payloads share a common envelope:

```json
{
  "event": "[PLACEHOLDER: event name]",
  "created_at": "2024-01-15T10:30:00Z",
  "data": {
    "id": "drv_456",
    "status": "onboarding_complete"
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `event` | string | The event type that triggered this webhook |
| `created_at` | string | ISO 8601 timestamp when the event was emitted |
| `data` | object | The resource object associated with the event |
