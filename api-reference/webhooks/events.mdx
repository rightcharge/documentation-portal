## Event catalogue

| Event name | When fired | Key payload fields |
| --- | --- | --- |
| [PLACEHOLDER: driver onboarding started event] | Driver begins onboarding journey | `driver.id`, `status` |

| [PLACEHOLDER: session costed event] | Cost calculation complete | `session.id`, `cost_gbp` |

| [PLACEHOLDER: reimbursement approved event] | Reimbursement approved | `reimbursement.id`, `status` |

## Subscribing to events

When you register a webhook endpoint, you can choose which events to receive. If you do not specify a filter, all events are sent to your endpoint.
